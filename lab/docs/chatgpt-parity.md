# Паритет с ChatGPT: что есть, чего нет, что включать

Сверка функций ChatGPT-класса ([обзор фич 2026](https://suprmind.ai/hub/chatgpt/features/),
[гайд](https://kingy.ai/news/the-complete-guide-to-chatgpt-everything-you-can-do-with-chatgpt-in-2026/))
с тем, что реально доступно в нашем Open WebUI 0.11 и что включено на демо (проверено по таблице
`config`, 341 ключ).

## Главный вывод
Большинство ChatGPT-фич в OWUI **уже есть в коде** — они просто выключены или не настроены.
Писать с нуля почти ничего не надо, надо включить и подключить бэкенды. Ограничение у нас не
функциональное, а инфраструктурное: airgapped-сеть (нет внешних API) и один-два преемптимых серва.

## Таблица паритета

| ChatGPT | У нас сейчас | Что нужно | Реалистичность |
|---|---|---|---|
| **Память между чатами** | код есть (`ENABLE_MEMORIES`, `memory.background_review`), НЕ включена | включить флаг | ✅ включить, 0 работы |
| **Code Interpreter** | **включён** (`code_interpreter.enable=true`, pyodide в браузере) | проверить в UI | ✅ есть |
| **Canvas / совместное редактирование** | нет canvas, но есть **артефакты** (HTML/SVG в панели) + CodeMirror с Run/Save | своё «полотно» = форк фронта | ⚠️ частично |
| **Projects (проекты)** | есть **папки** с общим системным промптом и файлами (`folders.enable=true`) | назвать проектами, задать промпт папке | ✅ есть, надо использовать |
| **Deep Research** | нет: нужен веб-поиск, а внешка закрыта | внутренний поиск (вики/Аркадия) как тулза | ⚠️ свой аналог |
| **Веб-поиск** | код есть (31 провайдер, включая `yandex`), НЕ настроен | ключ внутреннего поиска | ⚠️ нужен доступ |
| **Голос (STT/TTS)** | код есть, движки пустые (`audio.stt.engine=""`) | локальный whisper или внутренний STT | ⚠️ нужен бэкенд |
| **Генерация картинок** | код есть, выключено (`image_generation.enable=false`) | внутренний image-бэкенд | ⚠️ нужен бэкенд |
| **Загрузка файлов и RAG** | есть (Files API, knowledge, 13 вектор-БД) | эмбеддер уже локальный | ✅ есть |
| **Автоназвание чатов, теги, follow-up** | **включено** | — | ✅ есть |
| **Автодополнение ввода** | выключено (`task.autocomplete.enable=false`) | включить | ✅ включить |
| **Компакция длинного диалога** | код есть, флаг не выставлен | включить порог | ✅ включить |
| **Субагенты** | код есть, выключено (`subagents.enable=false`) | включить осторожно (×20 нагрузка) | ⚠️ риск для сервов |
| **Шэринг чата ссылкой** | есть | включить право | ✅ есть |
| **Мобильный/PWA** | есть из коробки | — | ✅ есть |

## Чего у ChatGPT нет, а у нас есть (наш дифференциатор)
Логпробы и near-miss анализ выбора инструмента, бюджет контекста в реальных токенах, разброс
сэмплов и mode-collapse, импорт бенч-роллаутов как чатов, арена чекпойнтов с DPO-парами,
генерация проекта файлами, статус сервов и GPU-пула. Для LLM-инженера это ценнее, чем Canvas.

## План: сначала бесплатные включения
1. **Память** (`ENABLE_MEMORIES`) — самая заметная ChatGPT-фича, у нас просто выключена.
2. **Автодополнение ввода** — заметно на глаз, стоит ноль.
3. **Компакция** — лечит длинные диалоги, у нас уже болело.
4. **Папки как «проекты»** — общий системный промпт на набор чатов.
5. Проверить **code interpreter** в UI (заявлен включённым).

Дальше — то, что требует бэкендов (голос, картинки, веб-поиск): отдельные решения, зависят от
доступа к внутренним сервисам.
